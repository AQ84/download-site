两种条目别混

· packages[] 里带 url → 渲染成外链按钮，蓝奏云 / GitHub releases / 别的网盘都用这个， 链接必须 http/https 开头，可以加 notes（会显示成 📌，放提取码正合适）。
· packages[] 里带 parts[] → 分片包，每片是站内 files/ 目录下的文件名。
· files[] → 站内单文件，只能指 files/ 目录下真实存在的文件， 名字里不能有 / 或 \。
· 外链塞进 files[] 会被当成站内文件名，点了 404。
